# Werken in deze codebase

Lees eerst `docs/architecture.md`: welke module waar leeft, hoe ze van elkaar afhangen en welke paden je per taak nodig hebt. Blijf binnen de module van de opdracht. Raak je het fundament (`src/lib/supabase`, `src/lib/auth.ts`, `src/lib/modules.ts`, `src/components/ui`) of `src/lib/mcp` aan, zeg dat dan vooraf.

Functionele uitleg per module staat in `docs/<module>.md`. Controleer met `npm run typecheck` en de tests van je module.
